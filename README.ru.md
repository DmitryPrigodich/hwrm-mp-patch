# HWMP Patch 2.4.5 candidate

Подготовлен экспериментальный **HWMP 2.4.5 Cataclysm**: общий бюджет SU, штатные лимиты авианосцев, счётчик под RU, цены строительства и четвёртая эмблема кушан. Владелец подтвердил запуск и читаемый интерфейс; пороги постройки, очереди и два клиента остаются полевыми тестами. **2.4.5 опубликована в Workshop** после ревью и проверки запуска. [Публикация и скачанная копия](docs/ru/WORKSHOP_RELEASE_2026-10-30.md). [Правила и проверки](docs/CATACLYSM_2_4_5.md).

Обновление2.4.1 убирает копии моделей материнского корабля и средней ракеты; корветные сохранены ради их звука попадания. [Разбор и метод проверки](docs/ru/ASSET_DEDUPLICATION_2_4_1.md).

[English — основной README](README.md)

Самостоятельный патч Homeworld Remastered на полной основе **Players Patch 2.3Test build21**. Оригинальные четыре расы, общие исправления механик и узкие принятые изменения баланса. Это **кандидат для полевых испытаний**: нативные автотесты проверяют отдельные случаи, сетевую приёмку ещё предстоит пройти.

## Что изменилось

- Исходные гравиполя корректно освобождают пересекающиеся ограничения, в том числе после проверенных загрузок. Сохраняются прежние запреты способностей и скорость.
- Перевозка возвращает выживших пассажиров; захват сохраняет исходное разрешение самоуничтожения каждого корабля; Dock-таймеры независимы по ship ID.
- Защитный истребитель обновляет набор ракет при замене целей с прежним счётчиком. Восстановлена недостающая привязка Vaygr Medium missile weaponfire.
- Принятые изменения: **старт Hgn/Vgr 6/6 сборщиков**, последний скоростной множитель трёх пушек Assault **4 → 1,2**. Исправлены два ранее разобранных ракетных несоответствия; общего нового перебаланса нет.
- Подсказки стройки/науки показывают действительное базовое время на выбранном языке. Поддерживаются English, French, German, Italian, Spanish и Russian. Основной язык документации и CMD — английский.
- Меню: родной фон HW2 с планетой, ряд знаков хиигарян/вэйгров/таиидан/кушан, подпись HWMP 2.4.5 и музыка **Inhibitors**. [Подробности](docs/ru/MENU_BRANDING.md).

## Что осталось тестерам

Два реальных MP-клиента с одинаковыми архивами; стандартные/2x старты и интерфейс; видимые корпуса и ремонт отрядов; оплаченный гиперпрыжок и отмена зарядки; реальный возврат к охране; полные Hgn↔Vgr матчи со сменой сторон и карт. [Подробный список](docs/ru/CLOSURE_CHECKLIST.md).

## Сборка и запуск

```powershell
python -m pip install -r requirements.txt
python tools/prepare_inputs.py
python tools/hwmp24.py --package --candidate
```

Кандидат: `local/HWMPPatch245-candidate`. Обычный установленный релиз 2.4.1 сохранён в `local/HWMPPatch24-release`. Для русского CMD-запуска: `HWMP Patch 2.4.cmd -Language Russian`. [Штатный лаунчер и обратимый переключатель слота](docs/ru/LOCAL_INSTALLATION.md). Опубликовано в [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3827773780) как **HWMP Patch 2.4.5 - Cataclysm (Field Test)**. Для сетевых испытаний всем участникам нужна одна версия Workshop: хеши архивов Toolkit отличаются от локальной сборки разработчика.

Поверх полного пакета не нужен второй Players Patch. Совместимость старых сохранений с уже активными полями не гарантируется. Новые проверки загрузки не означают приёмку всех кампаний и переходов уровней.
