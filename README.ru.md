# HWMP Patch 2.4.5 — Cataclysm

[English](README.md)

Самостоятельный мультиплеерный патч Homeworld Remastered на основе **Players Patch 2.3Test build21**, с четырьмя исходными расами. [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3827773780). Используйте полный пакет отдельно и одинаковую Workshop-версию на всех MP-клиентах.

**Cataclysm — экспериментальный режим с известным дефектом ограничения SU:** постройка может запрещаться раньше времени, а некоторые составы превышают показанный бюджет. [Известные проблемы](docs/ru/KNOWN_ISSUES.md). Это обновление округляет потолки, но не исправляет дробный учёт цен кораблей.

## Cataclysm

Выберите **HWMP 2.4.5 Cataclysm** в Game Type. Бюджеты: Small 1440, Normal 1920, Large 2560, Huge 3840, Vast 7680. Штатные количественные ограничения авианосцев/верфей и бесплатных зондов сохранены; авианосцы вместимость не добавляют. Цены SU видны в строительстве, подсказках и выборе корабля; сумма готового флота — под RU. Очереди в счётчик не входят. [Правила](docs/ru/CATACLYSM_2_4_5.md) · [Цены](docs/ru/SUPPORT_UNITS_PRICES.md).

## Общие исправления

- Восстановление исходных разрешений/скорости после гравиполей, включая отдельно проверенные новые сохранения.
- Возврат груза фрегата-перевозчика, индивидуальные разрешения захвата/самоуничтожения и таймеры зависшей стыковки.
- Обновление ракетных целей защитного истребителя таиидан и восстановление weapon-fire средней ракеты вэйгров.
- Старт хиигарян/вэйгров6/6 сборщиков, последний скоростной множитель Assault Frigate1,2 и две узкие ракетные правки.
- Время стройки/науки в подсказках на шести штатных языках; четыре эмблемы исходных рас и музыка Inhibitors.

Старт/UI и отдельные механики проверены; баланс полных матчей и синхронизация двух клиентов ещё не подтверждены. Старые saves с активными гравиполями до нового журнала не гарантируются. [Приёмка](docs/ru/CLOSURE_CHECKLIST.md).

## Сборка и разработка

Нужны собственные игра, Toolkit и закреплённые входные данные Test21. Игровые ассеты в Git не входят.

```powershell
python -m pip install -r requirements.txt
python tools/prepare_inputs.py
python tools/hwmp24.py --package --candidate
```
