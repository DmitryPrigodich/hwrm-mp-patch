# HWMP Patch 2.4.6

[English](README.md)

Самостоятельный патч Homeworld Remastered для четырёх оригинальных рас на основе Players Patch 2.3 Test build 21.

**В 2.4.6 Support Units удалены.** Нативные тесты подтвердили дефект ограничителя 2.4.5; отдельный эксперимент 2.4.6 пока не обеспечивает резервирование очередей. Восстановлены штатные лимиты, убраны выбор Cataclysm, счётчик и цены SU. Остальные улучшения сохранены.

## Что осталось

- Восстановление способностей и скорости после гравиколодцев, включая проверенные сценарии сохранений.
- Восстановление груза фрегата поддержки, права на самоуничтожение при абордаже и отдельные таймеры зависшего докования.
- Перехват ракет таииданским истребителем, привязка средней ракеты вэйгров и две точечные ракетные правки.
- По шесть коллекторов на старте хиигарян и вэйгров, согласованный последний коэффициент точности штурмового фрегата 1.2.
- Подсказки времени постройки и исследований на шести языках; исправления русских названий, четыре эмблемы рас и музыка меню.

## Разработка

Полная сборка требует своих файлов игры, Toolkit и закреплённого Test21. Для проверок кода игровые ассеты не нужны:

```powershell
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
```

Отдельный кандидат:

```powershell
python tools/prepare_inputs.py
python tools/hwmp24.py --package --candidate
python tools/install_hwmp24.py --candidate
```

Последняя команда только показывает план установки. `--install` применяет его по явному запросу. Кандидат: `local/HWMPPatch246-candidate`, обычная сборка: `local/HWMPPatch246-release`. Исходники и квитанции этих сборок разделены; прежние релизы сохранены. Запуск с `-O`/`-OO` или `PYTHONOPTIMIZE` отклоняется до работы инструмента.
