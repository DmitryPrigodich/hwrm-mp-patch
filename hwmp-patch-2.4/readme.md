# HWMP Patch 2.4 — development build 1

Отдельный мод Homeworld Remastered на базе полного **Players Patch 2.3Test build21**. Сохраняет его мультиплеерный баланс и добавляет исправления скриптов и отдельных несогласованных записей данных. Это рабочая версия проекта Дмитрия, не официальный релиз команды Players Patch.

**Граница разработки:** здесь общая база и оригинальные четыре расы. Принята цепочка **HWMP Patch2.4 → HW1 Races Reimogined → Vast Reaches Mod**: новые расы/их баланс разрабатываются во втором слое, кампания — в третьем. Подробности — `docs/MOD_LAYERS.md` проекта и `mod-layers.json`.

## Исправления

- Гравиполя сохраняют исходные разрешения способностей и множитель скорости отдельно для каждой записи отряда. Перекрывающиеся поля снимают только собственную блокировку; уничтожение генератора освобождает её. Чужое поле продолжает удерживать цель. Подробный лог включается только через `HWMP_Debug=1`.
- Захват и перевозка на вспомогательных фрегатах возвращают сохранённые Dock/Scuttle/Attack вместо безусловного включения. Новое API позволяет сценарию обновить разрешения во время действия временного эффекта.
- Защитный истребитель обновляет локальные вражеские ракетные цели с прежним интервалом callback1.25с, включая замену целей при том же общем количестве ракет и приказ без корабельной цели. После перехвата возвращается к сохранённой охране. Союзные/далёкие ракеты отфильтровываются.
- Повтор Dock выдаётся после остановки под атакой на3с, затем не чаще раза в5с. Потери аппаратов не выводятся из `SobGroup_Count`; движущийся, уже пристыкованный или лишённый Move/Dock отряд не получает повтор.
- Деление SobGroup выдаёт плотный список без пустой последней группы. Список активных кораблей очищается перед пересборкой и исключает выбывших игроков.
- Подсказки времени выбирают RU/EN через штатный alias locale. Неизвестный UCS-ID сохраняется без ошибки и без принудительной английской подмены. Время подписано как базовое: бонусы производства не рассчитываются этим справочником.

Ракетная правая пусковая платформы получает заявленную PR23 дальность5500 вместо6000. У ракетного корвета удалён конфликтующий коэффициент SuperUtilityArmour0.8; остаётся0.85 по PR20. Остальные параметры этих двух оружий, цены, экономика, баллистика и научные деревья Test сохранены. Подробности — docs/MISSILE_AUDIT.md. Перенаведение ракет движком не объявляется исправленным. Кампания Vast Reaches, её корабли, наука, речь и ролики в этот самостоятельный мод не входят.

Аудит данных от 23 октября: справочник времени теперь генерируется из всех 183 проектов (187 записей четырёх рас), включая 32 прежде пропущенных проекта. Пустые служебные описания не заполняются. У Asteroid0–Asteroid4 восстановлены UCS-ссылки в имени/описании; RU и физика сохранены. Подробности и оставшиеся ограничения — docs/DATA_AUDIT.md, отчёт — local/data-audit/audit.json.

## Подготовка и запуск

Готовый пакет: `local/HWMPPatch24-release`, ZIP рядом. Путь подготовленного исходника записан в `local/hwmp-patch-2.4/manifest.json` (короткий каталог кеша для Archive.exe). Сборка ничего не устанавливает и не запускает. Явная установка: `python tools/install_hwmp24.py --install`; по умолчанию установщик только печатает план. Используется собственный каталог `HomeworldRM/DataWorkshopMODs/HWMPPatch24`; не заменять BananaDLC или слот Vast Reaches. Стартер ожидает там основной BIG и языковые BIG рядом. Не подключать второй экземпляр Players Patch поверх этого мода.

```powershell
.\.venv\Scripts\python.exe -X utf8 tools/hwmp24.py --package
.\.venv\Scripts\python.exe -X utf8 tools/verify_hwmp24.py
```

Скриптовые regressions проверяют перекрытия, прежние запреты, обновление сценарных разрешений, уничтожение генератора, выбор ракет и возврат к охране, Dock и RU/EN. BIG проходит самопроверку и полную распаковку со сравнением хешей основного и языковых пакетов. Это не тест HWRM, боя, сохранения/загрузки или сетевой синхронизации. До таких тестов версия остаётся development build.

## Наследование следующими модами

Общие исправления принадлежат этому репозиторию. hwrm-hw1-races-reimogined подключает закреплённую ревизию через dependencies/mp-patch; hwvr-to-hwrm-mod получает основу через расовый слой. Сборка этого репозитория не импортирует и не готовит кампанию или новые расы.

При временной блокировке миссиям следует использовать `HWMP_SetAbilityAllowed`/`HWMP_SetSpeedAllowed`: они меняют базовое разрешение, сохраняя активный эффект. Внешнее прямое изменение тех же engine-флагов во время блокировки автоматически отследить нельзя. Добавочные типы целей регистрируются через `HWMP_RegisterGravityTarget`.
