# Локальная установка

[English](../LOCAL_INSTALLATION.md)

Кандидат отделён от установленных модов и всё ещё опубликованной в Workshop 2.4.5.

```powershell
python tools/hwmp24.py --package --candidate
python tools/install_hwmp24.py --candidate
```

Вторая команда — план без записи. Добавлять `--install` по запросу владельца и после закрытия игры/лаунчера. Установщик проверяет переносимую квитанцию выбранного пакета, состав и хеши, сохраняет прошлую установку и отказывает при посторонних файлах/ссылках. Игру не останавливает и не запускает. Без `--candidate` выбирается отдельный обычный пакет 2.4.6.

Принадлежащая установщику папка — только `HomeworldRM/DataWorkshopMODs/HWMPPatch24`; оригинальный BananaDLC и другие моды защищены. У нативного лаунчера один локальный слот; его переключение — отдельная обратимая операция с резервом. `HWMP Patch 2.4.cmd` — существующий прямой стартер (техническое имя сохранено); `-Language Russian` выбирает русский, `-PrintOnly` печатает команду. Явный запуск стартера открывает обычное меню.

Для отдельно запрошенного переключения слота `launcher_slot.py hwmp --candidate` показывает план; `--apply` применяет его. `launcher_slot.py previous --apply` возвращает сохранённый прежний слот. Не выдумывать номера подписок и не менять файлы работающей игры. [Полный порядок](UPDATE_WORKFLOW.md).
