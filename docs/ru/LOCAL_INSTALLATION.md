# Установка и штатный лаунчер

[English](../LOCAL_INSTALLATION.md)

`python tools/hwmp24.py --package` собирает выпуск. `python tools/install_hwmp24.py` показывает план; `--install` обновляет только собственную HomeworldRM/DataWorkshopMODs/HWMPPatch24. Релиз/хеши/полная распаковка проверяются, прежняя версия копируется вне игры. Закрой игру/лаунчер сам: утилиты их не останавливают.

CMD по умолчанию английский; русский: `HWMP Patch 2.4.cmd -Language Russian`. Также French/German/Italian/Spanish. `-PrintOnly` не запускает игру.

У штатного лаунчера один локальный слот Gearbox/BananaMothership плюс настоящие подписки Steam. Сейчас он может временно показывать HWMP вместо Vast Reaches:

```powershell
python tools/launcher_slot.py hwmp --apply
python tools/launcher_slot.py previous --apply
```

Первая команда выбирает HWMP, вторая возвращает точную предыдущую копию VR. Без --apply выводится план. Открыть обычный лаунчер → Mods → Remastered → HWMP Patch2.4 → Launch. Язык берётся из Steam; в аргументах можно указать -locale Russian.

Переключатель сохраняет весь предыдущий слот в local/launcher-slot/backups/<UTC> и сверяет каждый файл, заменяет только свои архивы/переводы/config/preview. Оригинальный BananaDLC остаётся; неактивный VR сохранён. Одновременно в этом локальном слоте виден один мод. Pins/код потребителей не меняются.

При возврате проверяет владение/инвентарь, восстанавливает перезаписанное и удаляет только известные добавления текущего выбора, без рекурсивного удаления слота. Чужая правка останавливает замену. Ошибка копирования вызывает rollback. После сбоя питания сохранить backups/state и проверить точный путь перед ручным восстановлением. Никогда не удалять BananaDLC/чужие Workshop-папки.

Настоящая публикация/подписка Workshop даст самостоятельный пункт лаунчера. Подготовка папки не является разрешением на публикацию.
