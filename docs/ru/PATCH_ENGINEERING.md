# Устройство патча

[English](../PATCH_ENGINEERING.md)

Основа — закреплённый Test21 плюс собственные overrides. Общие механики/исходные расы здесь; новые расы и кампания — в потребителях.

Временный эффект хранит исходное разрешение каждой способности/скорость и набор владельцев. Освобождение одного владельца не снимает другой. Native SobGroup membership служит checkpoint-журналом; Lua-таблицы — кеш. HWJB хранит биты в членстве, HWJC кодирует числа/владельцев, HWJ управляет журналом, HWMP предоставляет API. Формат/namespace нельзя менять без решения о миграции.

Компактные целые/доли1/256, общий список владельцев и24-bit masks заменили медленный первоначальный64-bit прототип; для прочих обычных значений есть полный числовой путь. Неизменённые записи не переписываются, известное поле только повторяет запреты, освобождение адресное по метке владельца. Длинные матчи ещё должны оценить обход исторических serial slots.

Гравиполе сохраняет loaded previous-target set и освобождает выход/finish/Destroy. Перевозка возвращает видимость и выживший груз; захват хранит Scuttle по ID до native Dock-запрета; Dock использует независимые ID-таймеры3/5с. Защитный истребитель обновляет цели при прежнем счётчике на штатном callback1,25с.

Сценарии меняют baseline через HWMP_SetAbilityAllowed/HWMP_SetSpeedAllowed; прямые чужие изменения engine-флагов автоматически не отслеживаются. Дополнительные gravity hull IDs регистрируются HWMP_RegisterGravityTarget. Кампания проверяет свой контекст отдельно.

Числа: Vaygr00/2x7→6 сборщиков, Assault последний535/4→535/1,2 на3пушках, платформа правая6000→5500 и конфликтующий ранний SuperUtility0,8удалён при сохранённом0,85. Medium WF — восстановление ресурса. Новых Flak/экономических коэффициентов нет.

Исходные API/mocks, Lua4, распаковка и native — разные уровни доказательства. Старые активные сейвы без baseline-журнала не гарантируются. После исправления автор26октября разрешил вновь рассматривать удержание новых рас в одиночной кампании; прежний категорический запрет больше не является обязательным дизайном. Реализация и кампанийные испытания остаются расовому слою.
