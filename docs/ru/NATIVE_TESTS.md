# Ручная нативная проверка

[English](../NATIVE_TESTS.md)

Используйте точную сборку и новые партии для всех четырёх рас. Проверьте обычный и Cataclysm режимы, панели, языки, строительство, смену владельца и сохранения. Никакой автоматический verdict не заменяет наблюдение человека.

Приоритеты: [приёмка](CLOSURE_CHECKLIST.md) и [известные дефекты](KNOWN_ISSUES.md). Для SU отмечайте показанное значение/потолок, очередь, траты RU, фактическое завершение; отдельно точное заполнение, недостаток/запас1SU, два производителя, отмену, паузу, потерю производителя и освобождение бюджета. Значение IsBuilding само по себе не доказывает начало строительства.

tools/native_checks.py создаёт локальную запись результата из autotests/manual-cases.ru.json без запуска игры. Это структурированный русскоязычный набор исследовательских сценариев с отдельными исходными гипотезами; текущие числа берите из действующих правил, а не из старых установочных статусов. Прежняя подробная инструкция сохранена в [архиве](../archive/2026-10-30/ru/PREVIOUS_NATIVE_TESTS.md).

В отчёте фиксируйте версию, хеши всех архивов, Game Type, карту, Unit Cap, расу, язык, шаги и повторяемость. Используйте not_run/blocked/partial для отсутствующего доказательства; не переименовывайте отрицательный результат в passed. Журналы/saves/сведения процессов остаются вне Git.
