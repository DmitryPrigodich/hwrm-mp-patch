# Код-ревью — 30 октября 2026

[English](../CODE_REVIEW.md)

Проверены целые потолки, диагностические инструменты и документация относительно опубликованной2.4.5: ошибки/регрессии, Lua4/API, обычные режимы, оптимизация, читаемость, расширяемость, локализация, упаковка и публикация кода без ассетов. Пользователь разрешил Git/Workshop-апдейт с явным описанием ограничений SU.

## Выводы и исправления

- **Известный дефект продукта остаётся:** малые дробные веса не обеспечивают номинальный SU-лимит. Ранний отказ UI и оплачиваемое guarded-превышение backend подтверждены. Целые потолки это не исправляют; точность SU и повышение стабильности не заявляются. [Ограничения](KNOWN_ISSUES.md).
- **Исправлен старый журнал:** одинаковый мир/токен мог принять предыдущий endpoint и закрыть незавершённый собственный тест. Теперь перед закрытием требуются новое содержимое и время после запуска. Хеш считается по тем же прочитанным байтам без гонки второго чтения. Offline-проверки охватывают старое/тронутое содержимое, время, отсутствующие/старые записи, свежий UTF16 и динамические Lua-ошибки.
- **Исправлено ложное доказательство стройки:** IsBuilding бывает ожидающей очередью. Начало подтверждается тратой RU/завершением; два флага очереди не доказывают параллельный прогресс. Это проверяет отдельная offline-Lua fixture.
- **Исправлена зависимость Equal от старого бюджета:** точный базис берётся из Normal сохранённого источника (1885/1900 либо1905/1920). Несовместимые цены, базисы и профили отклоняются. Старые журналы не переписываются.
- **Исправлена упаковка документов:** канонические README и текущие EN/RU страницы получают рабочие ссылки плоского релиза. История — в архиве; происхождение цен — Markdown; цены/пины/квитанции — функциональный JSON. Русский ручной манифест перенесён без изменения байтов/хеша; создание протокола кандидата поддерживает --candidate.
- **Исправлены метаданные обложки:** preview-spec всё ещё описывал старую2.4. Теперь он соответствует неизменной согласованной2.4.5обложке и её хешам; изображение не менялось.
- **Добавлены проверки конфигурации:** целый потолок и совпадение native_scale. Цены/характеристики кораблей, обычные режимы и runtime-производительность не менялись; HUD по-прежнему просто суммирует владение раз в1с.
