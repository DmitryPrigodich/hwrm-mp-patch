# Публикация Workshop — 26 октября 2026

[English](../WORKSHOP_RELEASE_2026-10-26.md)

Опубликован [HWMP Patch 2.4 - Field Test](https://steamcommunity.com/sharedfiles/filedetails/?id=3827773780), ID **3827773780**, игра **244160**. Steam подтвердил загрузку файлов и обложки; неавторизованный API подтвердил публичную видимость. Страница проверена в браузере владельца. Отдельный анонимный HTTP-запрос получил ограничение частоты 429 и не считается успешной проверкой страницы. Обложка, статус полевых испытаний и credits проверены. Оформленное владельцем описание сохранено обратно в английский исходник.

Скачанная через Steam копия: семь BIG прошли CRC и полную распаковку с совпадением хешей всех **1136** исходных ресурсов; проверены штатные TOC data/locale и обложка. Суммарный размер — **110014186 байт**. [Точный состав и хеши](../../workshop/published-release.json).

Toolkit перепаковал файлы, поэтому хеш главного BIG **6733149b…** отличается от локального **0e306ebe…**. Содержимое проверено, но для сетевых испытаний всем нужна одна версия Workshop. Игра при публикации не запускалась; нативная загрузка языков/меню, два сетевых клиента и полные матчи остаются на полевую проверку.

Следующие пакеты сохраняют ID через workshop/item.json; команда для обновления — **update**, а не create. Потребители и резерв Vast Reaches не менялись.
