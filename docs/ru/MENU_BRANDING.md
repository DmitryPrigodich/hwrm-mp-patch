# Меню и музыка

[English](../MENU_BRANDING.md)

Использованы родные фон кампании HW2 с планетой/синей туманностью, надпись Homeworld/Remastered и белый знак таиидан. Снизу добавлено Multiplayer Patch2.4 родным Heading2Font. Это английское название продукта для всех языков; кнопки продолжают использовать штатный перевод.

Wordmark обрезается UV до верхних192строк исходного1024×512: прежний хиигарский знак не рисуется, знак таиидан — отдельный квадратный элемент. Имена служебных version/build labels оставлены движку, а их вывод скрыт. В углу остаётся только HWMP2.4.

Музыка — Inhibitors: data:sound/music/staging/STAGING_04 из4миссии HW2RM. Файл уже есть в общем Music.big; новый звук не копируется. Из soundconfig меняется только FEMusic, остальные боевые треки/громкости/настройки сохраняются. Native FEMusic также является запасной музыкой миссии без собственного трека; дополнительных циклов или боевых callbacks нет.

Генератор tools/menu_branding.py и baseline/menu-inputs.json закрепляют источники. Три родные текстуры копируются локально без изменения байтов, в Git не входят. Проверены Lua4, структура/подписи меню, исходники и payload BIG; визуал/размер шрифта/прослушивание/переход в матч требуют проверки человеком. Игра не запускается автоматически; расы/кампания/pins не обновляются.
