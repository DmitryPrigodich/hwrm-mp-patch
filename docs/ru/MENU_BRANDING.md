# Меню и музыка

[English](../MENU_BRANDING.md)

Меню использует родной фон HW2 с планетой и надпись Homeworld/Remastered. Под ней в один ряд расположены четыре отдельных белых знака: **хиигарян, вэйгров, таиидан, кушан**. Ниже — **Multiplayer Patch 2.4.5** штатным Heading2Font. Название продукта остаётся английским на всех языках, кнопки сохраняют штатную локализацию. В правом нижнем углу — **HWMP 2.4.5**.

Исходная текстура 1024×512 содержит надпись в верхних 192 строках, а синий хиигарский знак начинается со строки 209. Исправленный `uvRect = {0, 0.375, 1, 0}` выбирает именно верхние строки. Первая версия ошибочно выбирала нижние 192 строки: скриншот пользователя подтвердил пропавшую надпись и обрезанный знак. Теперь эмблемы используют отдельные штатные текстуры, одинаковые квадратные рамки и общую горизонтальную ось. Дочерние элементы заданы явными индексами для Lua 4.

Имена служебных элементов версии сохранены для движка, их отображение скрыто. Отдельная подпись патча не меняет сетевую версию игры.


Три названия в списке Game Type заменены на `Homeworld RM - HWMP 2.4.5`, `Homeworld 1 RM - HWMP 2.4.5` и `Homeworld 2 RM - HWMP 2.4.5`. Это единые названия продукта на всех языках. В скриптах правил меняется только GameRulesName; GUID, SaveGameVersion, фильтры рас/карт, параметры и игровая логика сохранены.

Музыка — **Inhibitors**, `data:sound/music/staging/STAGING_04` из четвёртой миссии HW2RM. Файл есть в общем Music.big; новый звук не копируется. Меняется только FEMusic, остальные боевые треки, громкость и настройки остаются штатными. По родному soundconfig FEMusic также служит запасным треком миссии без собственной музыки. Дополнительных циклов воспроизведения нет.

Генератор `tools/menu_branding.py` и `baseline/menu-inputs.json` закрепляют источники. Шесть родных текстур копируются локально без изменения байтов и не входят в Git. Редактировать следует шаблон, затем пересобирать через hwmp24.py. Отдельный режим Cataclysm описан в CATACLYSM_2_4_5.md; новые расы не добавляются.

Проверки охватывают Lua 4, таблицы меню, диапазон строк текстуры, порядок эмблем, подписи и содержимое всех BIG. Исправленную компоновку, размер шрифта и звучание ещё нужно подтвердить в самой игре.

В кандидате 2.4.5 добавлен отдельный Game Type HWMP 2.4.5 Cataclysm. Кушанский знак и новая компоновка ещё не проверены в игре. Установленная/опубликованная версия остаётся 2.4.1.
