# Диагностические сценарии SU

[English](../SU_BOUNDARY_TESTS.md)

Это отдельные стенды, не обычный мод. [Известный дефект](KNOWN_ISSUES.md), [архив нативных результатов](../archive/2026-10-30/ru/SU_ACCOUNTING_2026-10-30.md). Результаты1900 сохраняют исходные данные; их не переименовывают в тесты1920.

## Границы бюджета

tools/su_boundary_tests.py prepare создаёт52мира:12ручных сценариев и один Auto из6случаев на расу. Цена записи перехватчиков: хиигаряне15, вэйгры14, кушане3, таиидане3. Точный наполнитель рассчитан для5профилей (360планов).

Control оставляет200SU и должен подтвердить оплаченное завершение. Under/Exact/Above дают цену−1/ровно цену/цену+1; Full/Over —0/−1. Parallel/ParallelExact дают две цены−1/ровно две цены. Cancel/Pause проверяют резерв, ProducerLoss — потерю производителя (сам авианосец освобождает40SU), FleetLoss — освобождение бюджета уничтожением отдельного сборщика.

Для текущего Normal 1920 хиигарский Exact стартует с1905. Два авианосца рядом; защищённый наполнитель вдали. Закройте предыдущую ручную сессию перед новым запуском. Команды: prepare, install, launch Hgn_Exact --language Russian, collect. Установка/запуск требуют запроса человека.

Auto специально вызывает low-level Build даже при CanBuild=0: это проверка обхода, не доказательство допуска обычного UI. Флаг ожидающей очереди не считается оплачиваемым прогрессом. Параллельное производство остаётся непроверенным без независимого наблюдения обоих производителей.

## Точность учёта

tools/su_accounting_tests.py prepare --scale 32 или prepare --scale 64 копирует неизменяемый подготовленный источник. Measure измеряет обычные типы; Equal — равные номинальные составы; EqualBuild проверяет CanBuild=1 перед КАЖДЫМ последовательным платным запросом; QuantumLow/High используют одинаковые определения зондов с одной тестовой категорией. Бюджеты/цены берутся из сохранённого источника. Equal стартует с Normal−15:1885 для архивного1900,1905 для нового1920. Неподдерживаемый меньший базис отклоняется; Equal требует профиль Normal.

Миры: Hgn_Measure, Hgn_Equal, Hgn_EqualBuild, Hgn_QuantumLow, Hgn_QuantumHigh, Hgn_Auto. После выбора делителя сначала prepare, потом install/launch. Подготовка сама не устанавливает и не запускает игру. Collect проверяет свежесть содержимого/времени журнала и мир/токен; close-terminal разрешён только своему процессу после свежего endpoint/ошибки. Здоровый тайм-аут оставляет игру открытой.

Журналы, копии источников, отклонённые пилоты и сведения процессов — в игнорируемом local/su-boundary-tests. Синтаксис/архивы не доказывают нативный тест игры/двух клиентов. [Правила стендов](AUTO_TESTS.md).
