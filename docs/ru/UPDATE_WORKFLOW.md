## Код и проверки без ассетов

```powershell
python -m pip install -r requirements-dev.txt
python -m black --check tools tests
python -m pyflakes tools tests
python -m unittest discover -s tests -v
```

Все активные инструменты отказывают при оптимизированном Python до работы. Критические пины и пути дополнительно проверяются явными исключениями. Редактировать ручные файлы из `hwmp-patch-2.4/manual-files.json`, генераторы и `tools/templates/effects.lua`. Генерация идёт в игнорируемый каталог `generated/` выбранной сборки; её результаты не редактировать. Объединённый шаблон эффектов сохраняет точные байты прежнего Lua.

## Сборка кандидата

```powershell
python tools/prepare_inputs.py
python tools/hwmp24.py --package --candidate
python tools/install_hwmp24.py --candidate
```

Пакет: `local/HWMPPatch246-candidate`, работа/квитанции: `local/builds/2.4.6/candidate`. Без `--candidate` используется отдельный `local/HWMPPatch246-release` и отдельный рабочий каталог. Пути передаются явно. Свежий staging исключает старые файлы; замена сохраняет предыдущий принадлежащий проекту пакет и откатывается при ошибке. `verification-package.json` находится внутри пакета, поэтому следующая сборка не портит проверку другого релиза. Все семь BIG полностью распаковываются и сверяются.

## Установка и проверка в движке

Последняя команда выше показывает план. По явному запросу владельца и после закрытия игры/лаунчера добавить `--install`. Самостоятельно игру человека не останавливать. [Установка](LOCAL_INSTALLATION.md). Для нативного теста записывать точные хеши; моки и CRC не доказывают поведение движка. SU остаются исключёнными до отдельной будущей реализации с нативной приёмкой учёта и очередей.

## Публикация

Сборка не означает загрузку в Steam. Проверить точные описания EN/RU и обложку, получить поручение на публикацию, затем обновить существующий item 3827773780. Подготовка использует выбранный контекст и его манифест. Скачанный из Workshop пакет проверяется отдельно. Квитанции опубликованной 2.4.5 и прежние исходники сохраняются как история; зависимости потребителей автоматически не продвигаются.
