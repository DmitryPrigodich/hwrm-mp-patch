# Функциональные данные и описательная документация

[English](../DATA_FORMATS.md)

Markdown описывает текущие возможности, процедуры и ограничения. JSON оставлен для входов инструментов, закреплённых хешей и квитанций. Данные конфигурации не заменяют руководство и не служат журналом разработки.

- design/cataclysm.json — цены, составы отрядов, расы и бюджеты для генератора/проверок.
- localization/*.json — словари интерфейса и отчёт покрытия языков.
- baseline/*.json — закреплённые входные данные/хеши для проверок и аудитов.
- autotests/manual-cases.ru.json — русские инструкции оператора, которые native_checks.py разворачивает в записи ручных проверок; это не игровой runtime.
- workshop/item.json — идентичность item для staging; published-release.json — текущая квитанция; releases/ — старые квитанции.
- docs/archive/**/evidence/*.json — архив структурированных наблюдений, а не описание текущих возможностей.

Из функционального Cataclysm JSON убраны устаревший статус, описательный текст политики и русские основания цен. Основания сохранены в архиве; [актуальные цены](SUPPORT_UNITS_PRICES.md) читаются в Markdown. Ручной тестовый JSON перенесён без изменения байтов/хеша в явно обозначенный языковой путь; [человеческая версия](NATIVE_TESTS.md) не требует читать JSON.

Релизный version.json нужен установщику: идентичность/контрольные данные остаются структурированными. Не заменять его прозой. Сырые журналы, saves, сведения процессов и извлечённые ассеты остаются локально вне Git.
