# Автоматические диагностические стенды

[English](../AUTO_TESTS.md)

Диагностика — отдельные пакеты Extra Missions, не содержимое обычного мода. Подготовка, синтаксис/CRC и endpoint доказывают только свой заявленный объём.

Общие механики: tools/auto_testgrounds.py и tools/run_auto_queue.py. SU: [инструкция](SU_BOUNDARY_TESTS.md), tools/su_boundary_tests.py и tools/su_accounting_tests.py. Анализаторы Tools/analyze_*.py читают локальные наблюдения; UI человека и MP проверяются отдельно.

Для нативного запуска нужен запрос человека. Сохраняйте хеши исходников/архивов и прежние журналы. Уже работающая игра блокирует запуск; во время очереди будущих запусков запрещена пересборка/установка. Закрывать можно только собственный идентифицированный процесс после свежего endpoint/ошибки. Здоровый тайм-аут оставляет игру открытой; пользовательскую игру не останавливать.

Свежесть определяется по содержимому предыдущего журнала и времени запуска, дополнительно к миру/токену. IsBuilding может означать ожидающую очередь: трата RU и завершение учитываются отдельно. Два флага очереди не доказывают параллельное производство.
