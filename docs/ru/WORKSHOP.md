# Обновление Workshop

[English](../WORKSHOP.md)

Существующий item: [3827773780](https://steamcommunity.com/sharedfiles/filedetails/?id=3827773780). ID и обложка владельца сохраняются; последующие согласованные выпуски — update без создания дубля.

1. Ревью кода, текущих EN/RU описаний и ограничений. Исходные/fixture/Lua4 проверки, полная распаковка/сравнение семи архивов кандидата. Коммит/push кода и документов без ассетов.
2. tools/prepare_workshop.py --candidate --preview <approved512image> --title <title> готовит loose runtime. Toolkit принимает исходные файлы, не готовые BIG. Диагностика, инструменты и личные журналы в payload не входят.
3. Публикация требует явного разрешения пользователя; подготовка сама по себе его не даёт. Текущий запрос разрешает обновление с новым описанием дефектов SU; перед отправкой показать конкретный итоговый текст. Лимиты: название128, описание8000символов, обложка512×512 меньше1MiB; GameType HomeworldRM, ModType MOD и прежний WorkshopID.
4. Использовать documented update-команду установленного Toolkit с подготовленной папкой. Пароли/коды аутентификации и обязательства автора обрабатывает владелец.
5. Проверить публичные название/описание/обложку и manifest; скачать подписную копию, проверить CRC и полностью распаковать/сравнить все7BIG с подготовленными loose-файлами. Хеши Toolkit и developer могут различаться.
6. Прежнюю квитанцию сохранить в workshop/releases; обновить published-release.json, текущий отчёт и Git. Сравнение содержимого не является нативным тестом игры/двух клиентов.
