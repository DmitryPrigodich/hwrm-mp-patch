# Локальная установка HWMP Patch 2.4

По решению Дмитрия 23 октября текущий способ — отдельный каталог и CMD. Публикация в Steam Workshop запланирована по завершении работы над патчем, сейчас не выполнялась.

Из корня репозитория:

```powershell
python tools/hwmp24.py --package
python tools/install_hwmp24.py
python tools/install_hwmp24.py --install
```

Первая команда собирает и полностью проверяет основной и языковые BIG. Вторая выводит план без записи в игру. Третья устанавливает проверенный выпуск в `HomeworldRM/DataWorkshopMODs/HWMPPatch24`. Сборка сама не устанавливает его. Если уже запущена игра или её Launcher, установщик останавливается и оставляет их человеку.

Перед обновлением существующий собственный пакет копируется с проверкой хешей в `local/installed-backups/<UTC>/HWMPPatch24`, за пределами игры. Установщик принимает только собственную метку `package-id.txt`, проверяет контрольные суммы выпуска и актуальность полной распаковки, отказывается от чужих файлов/ссылок в своём каталоге. Прочие моды, штатные архивы и профили не меняются. Результат и защищённые хеши — `local/installation.json`.

Запускать `HWMP Patch 2.4.cmd` в установленной папке. По умолчанию русский. `HWMP Patch 2.4.cmd -Language English` выбирает английский; `-PrintOnly` только печатает команду, без запуска. Стартер открывает обычное меню, откуда доступны скримиш и мультиплеер. Подключать второй Players Patch поверх полного пакета не нужно.

## Почему мод пока не в штатном списке

Пассивно проверен код установленного `HWLauncher/Launcher.exe` (SHA фиксируется в локальном отчёте; приложение не запускалось). `CWorkshopItem.GetModPathFolder` строит путь под SteamID. `MainWindow.SubscribedItems` обрабатывает подписки Steam, а цифровые папки без подписки ставит в очередь удаления. `AppendGearboxWorkshopItemsList` добавляет единственный жёстко заданный локальный `Gearbox/BananaMothership`.

Поэтому произвольная папка с `config.txt` не становится отдельным пунктом. Поддельный WorkshopID/цифровой каталог тоже не является регистрацией и может быть удалён лаунчером. Мы используем устойчивый нецифровой каталог `HWMPPatch24` для прямого `-workshopmod`. Занятый Vast Reaches слот BananaMothership, его конфигурация и оригинальный BananaDLC сохраняются. После настоящей публикации и подписки Steam штатный путь станет отдельным вариантом установки.

Установка и `-PrintOnly` не являются подтверждением загрузки в движке. Первые нативные действия описаны в [NATIVE_TESTS.md](NATIVE_TESTS.md).
