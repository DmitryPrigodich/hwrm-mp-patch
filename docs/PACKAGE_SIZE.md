# Package size

[Русский](ru/PACKAGE_SIZE.md)

The published Workshop download totals **110,014,186 bytes** across seven BIGs, config and preview. The pinned original Test21 BIG is **105,147,823 bytes**; the local HWMP primary is **109,331,829 bytes**. These are compressed archive/package sizes; Toolkit compression and TOCs account for its separately recorded hashes/sizes.

Largest categories before archive compression:

| Source category | Bytes |
|---|---:|
| Map TGA previews | 144,954,529 |
| Ship HOD models | 57,950,605 |
| Ship DDS textures | 5,418,408 |

The Hiigaran mothership HOD alone is 29,495,305 bytes. The five native menu textures total 9,175,260 source bytes; the menu/branding work added about 4.2 MB to the compressed local archive. Inhibitors uses the game's shared Music.big. Most weight comes from the complete inherited Test21 payload. Lower-resolution map previews are a potential size optimization, requiring separate visual review; no preview/model assets were removed or recompressed for this release.
